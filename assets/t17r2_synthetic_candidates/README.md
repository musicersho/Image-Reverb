## 任務卡需求

依 TASKS.md「T-17-R2／Fable 落地／§1」：浴室、居住空間、教堂或大空間、樓梯間或走廊、車內後座視角各至少一張。五類供 §7-1 新盲聽測試（≥4/5）；不能取代 §7-2 有真實 IR 的場地對照。

- 橫幅、一般透視、非全景；地板、天花板與至少兩面牆可見。車內對應底部腳踏區、頂棚與左右車艙側面。
- 比例不可為 2:1 ±5%；4:3 或 16:9 可用。
- JPG／PNG／HEIC，長邊 ≥1920px，原檔不裁切；無字幕、播放器 UI、黑邊，盡量無人、均勻照明。
- 正式路徑 `assets/photos_heldout/heldout_{bathroom,living,hall,corridor,car}.*`；SOURCES §4 記來源。不得曾用於調參、標註或校準；R2 開跑時須查歷史 sha256。
- 使用者附大約尺寸與六面材質；缺材質時標 GT 缺，不能憑提示詞填成 `confirmed_by: user`。尺寸用於判最大邊 ≤10m／>10m，車內為非房間域外。
