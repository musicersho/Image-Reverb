# 真實空間素材——拍攝與交件說明（給使用者；TASKS.md T-64）

這批照片有兩個用途：一半當**開發集**（拿來改進尺寸估計與材質建議），一半**封存**當下一次 MVP 驗收（T-17-R3）的 held-out。
哪一張進哪一邊由程式依檔案指紋決定，您不用管、也請不要指定。

## 要拍哪些空間

至少 **8 個空間**，能 10 個最好。下面五類**每類至少 1 個，能 2 個最好**，其餘用小房間補：

| 類別 | 例子 |
|---|---|
| 浴室 | 家裡、工作室、旅館的浴室 |
| 客廳／臥室 | 任何住宅尺度的房間 |
| 大空間 | 教室、禮堂、教堂、體育館、大廳（空一點的更好） |
| 走廊／樓梯間 | 公寓樓梯間、辦公室走廊 |
| 車內 | 坐在後座往前拍，或前座往後拍 |

## 怎麼拍

1. 手機**主鏡頭 1x、橫拍**，不要用超廣角（0.5x）、不要用人像模式、不要裁切或修圖。
2. 站在房間一端（靠牆或靠角落），朝最長的方向拍，盡量讓**地板、天花板、左右牆**都入鏡。
3. 每個空間 1–2 張（第二張可從另一端反方向拍）。
4. **傳原檔**：用 AirDrop 或傳輸線放進電腦。**不要經 LINE／Messenger／微信**（會壓縮並洗掉鏡頭資訊）。HEIC 或 JPG 都可以。

## 每個空間要附的資料（填 `空間資料表.md`）

1. **大約尺寸**：長 × 寬 × 高（公尺）。捲尺最好，步距也可以（一大步約 0.75 m）；高度可用「我身高＋手舉高還差多少」估。
2. **六面材質**：地板、天花板、正對鏡頭的牆、左牆、右牆、背後的牆，各選一個最接近的：
   混凝土／磚／木板／石膏板或一般粉刷牆／玻璃／大理石或磁磚／地毯／布幕窗簾／吸音板／座椅或人群／草地泥土／塑膠壁板／橡膠地墊／金屬屋頂浪板／不確定。
3. 房間裡的大型軟家具（床、沙發、厚窗簾…）大概有哪些。

## 選配但很有用：現場錄一段聲音

對 10 公尺以下的房間特別有價值——目前專案**只有 1 個**小空間有真實殘響可以對照。
- 手機「語音備忘錄」（iPhone 請到 設定 → 語音備忘錄 → 音訊品質 選「無損」）。
- 站在房間中間，手機放桌上或請人拿著，離您 2 公尺以上。
- **用力拍手 3 下，每下之間安靜等 5 秒**（刺破氣球更好）。錄音期間不要講話、關掉冷氣風扇更好。
- 傳原檔（`.m4a`／`.wav`）。

## 放哪裡

每個空間一個資料夾：`assets/incoming_real/<代號>/`，代號用英數字，例如 `bathroom_home`、`stairwell_office`。
照片、錄音都丟進去，再填同一層的 `空間資料表.md`。放好後開 Sonnet 視窗貼：
