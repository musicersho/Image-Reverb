# Divorce Beach

- **場地類型**：戶外沙灘＋岩礁（開放空間，幾乎沒有封閉反射面）
- **官方名稱**：`DivorceBeach`（EchoThief library 分類：`Nature/`）
- **地點**：Divorce Beach（Playa del Divorcio），Cabo San Lucas 一帶，Baja California Sur, Mexico
  ※ 地點依 EchoThief 網站與同批 Baja California Sur 錄音推定，網站頁面本身只寫場地名，未標國家。
- **網站標註材質**：`Sand, sandstone, tears.`（沙、砂岩、以及作者的玩笑話「淚水」）

## IR 檔案

- 檔名：`DivorceBeach.wav`
- 取樣率：44100 Hz
- 長度：0.979 秒（本批最短，符合戶外開放空間的預期）
- 聲道數：2（stereo）
- 位元深度：24-bit PCM
- RMS：0.028022　峰值：0.998821（非靜音）
