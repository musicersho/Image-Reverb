## 資料意義

所有長×寬×高都是**生成時設定的大約尺寸**，不是用捲尺、步距或照片量得；圖像也不保證嚴格符合這些數字。六面材質列的是各面主材，混合材質與家具遮擋另註。背後牆只有設計值，照片觀測為 `unknown`。材質外觀不能證實內部結構、吸音係數或是否為吸音板。

車內尺寸是非長方體車艙的包絡設定；天花板「布幕窗簾」只是對 README 選單的近似分類，實際設定為頂棚織布；前方與左右皆為混合材質，表中已說明。未寫入 `user_measured` 或 `confirmed_by: user`。

本次是使用者明確要求的**合成素材交付**，不是執行 T-64 的真實素材分組／封存。照片放在獨立目錄，不混入 `incoming_real`、`photos_real_dev` 或 `photos_real_heldout`；沒有分組，未跑深度、分割、gate、IR 或驗收腳本。T-64「等使用者真實素材」狀態不變。
